# Integração

Copiar HTML/CSS/JS e seus caminhos relativos. Sem dependências externas, rastreamento, API ou envio de dados. Fontes locais WOFF licenciadas. CSS controla enquadramento das fotos originais e oculta margens de interface das capturas pelo overflow do contêiner; originais PNG preservados.

As seções permanecem legíveis sem JavaScript. Só ativar camadas de motion depois de ambas as imagens carregarem; erro mantém foto estática. IntersectionObserver é opcional; ausência revela tudo. Respectar reduced-motion.

Antes de publicar, confirmar dados comerciais com o proprietário, revisar Safari/Chrome/Firefox, mobile e teclado. O estudo não foi validado visualmente num navegador real nesta entrega. A composição gerada é referência de direção; o HTML aproxima o efeito com código e fotos reais.
