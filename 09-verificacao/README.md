# Verificação

Node: node 09-verificacao/testar-controles.cjs
Python com Pillow: python3 09-verificacao/validar-arquivos.py

O primeiro teste cobre o contrato dos controles com um DOM mínimo. Não simula layout ou motor de navegador. O segundo confere arquivos locais, JSON, alpha e hashes.

Revisão de publicação: Chrome, Safari, Firefox; 390px e 1440px; teclado, contraste, logo, posição dos copos, orientação do telefone e reduced motion. Validar dados comerciais. Vídeo e maquetes são composições ilustrativas.
